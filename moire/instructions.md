# Генератор муаровых узоров

Муа́ровый узор (муа́р, от фр. moire, название ткани) — узор, возникающий при наложении двух периодических сетчатых рисунков. Явление обусловлено тем, что повторяющиеся элементы двух рисунков следуют с немного разной частотой и то накладываются друг на друга, то образуют промежутки.

Надо написать генератор муаровых узоров. Он отображает множество сеток на фоне определённого цвета. Он представляет собой холст + стандартный сворачиваемый блок настроек, как в остальных проектах (см. каталоги formulas-audio-lab, sound).

## Блок настроек:
- Кнопка "Сохранить" (сохраняет в .png)
- Цвет фона
### Список сеток
Для каждой сетки можно настроить:
- тип сетки (клетка под 90 градусов, шестиугольники, треугольники)
- цвет
- прозрачность
- шаг сетки
- наклон в градусах
- сдвиг по X / по Y

Для всех элементов настроек лучше использовать стандартные ползунки с кнопками, как в formulas-audio-lab, для выбора цвета использовать стандартный диалог браузера. 

Язык интерфейса английский.
